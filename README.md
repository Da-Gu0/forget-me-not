# 勿忘我 · 赵奶奶篇

> 一款关于阿尔茨海默症的 HTML5 交互叙事游戏

## 项目简介

《勿忘我·赵奶奶篇》是一款以第一人称视角展开的叙事游戏。玩家扮演一名志愿者，陪伴患有阿尔茨海默症的赵奶奶，通过五个陪伴关卡，逐步了解她遗忘的过去——一位植物研究所研究员的青春记忆。

## 快速开始

直接用浏览器打开任意 `visit*.html` 或 `index.html` 即可游玩，无需服务器。

| 文件 | 内容 |
|------|------|
| `index.html` | **整合版**（包含全部 5 关，推荐） |
| `visit1.html` | 陪伴一 · 枯萎的花 |
| `visit2.html` | 陪伴二 · 标本盒 + 野外记录本 |
| `visit3.html` | 陪伴三（构建产物） |
| `visit4.html` | 陪伴四（构建产物） |
| `visit5.html` | 陪伴五（构建产物） |

## 文件分工

### 核心关卡

- **`visit2.html`** — **主要修改文件**，标本盒交互、野外记录本翻页、证件照翻转卡片等复杂功能都在此实现
- **`visit1.html`** — 陪伴一，枯萎的花解谜
- **`visit3.html` ~ `visit5.html`** — 由构建脚本生成

### 构建系统

```
assemble.ps1  →  将 visit2.html 的框架逻辑注入 _vN_story.js 生成 visit3/4/5
```

- `assemble.ps1` — PowerShell 构建脚本
- `_v3_story.js` / `_v4_story.js` / `_v5_story.js` — 陪伴三/四/五的故事数据

### 资源文件

### 备份文件

`game_backup_*.html` — 各版本的自动备份，保留供参考。

## 技术栈

- 纯前端 HTML5 / CSS3 / Vanilla JavaScript
- CSS 3D 翻转卡片动画
- CSS 滑动翻页动画
- 打字机效果对话系统
- 状态机驱动的交互系统

## 开发者注意事项

- 修改关卡内容时，**主编辑 `visit2.html`**（模板文件），再运行 `assemble.ps1` 同步到 visit3/4/5
- 仅 `visit1.html` 和 `visit2.html` 为手写文件，`visit3/4/5` 为构建产物
- 角色立绘的显示/隐藏由 `setSpeaker()` 函数控制
